评审修正清单

这次设计稿相对你当前实现的具体改动点，按优先级排列。代码尚未改动，仅在此可视化。

  • P0
    统一单一蓝色 accent移除散布在 10 个 CSS 文件、43 处的硬编码紫。新增 --accent-fg / --accent-tint，导航激活、选中行、徽章、主按钮都走同一套蓝。
  • P0
    补齐缺失 token--hover、--blue 在 :root 未定义却在使用，导致下拉菜单 hover 无反馈、图标无色。补别名后恢复。
  • P1
    修掉 accent-soft 当文字色原 12% 填充色被当文字色用 33 处，浅底上几乎不可读。改用可读的 --accent-fg。
  • P1
    阅读排版升级正文 14→15px、行高 1.75、限宽 70ch；reader 标题补显式阶梯，文档标题提到主导层级。
  • P1
    内容主导阅读标签/摘要/关联收进折叠区，打开正文即可读。
  • P2
    清理死 CSS重复定义的 .reasoning-event、.spin、.document-tabs 去重并加作用域。
