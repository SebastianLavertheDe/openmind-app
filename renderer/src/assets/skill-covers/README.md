# New-task recommendation covers

Original raster assets generated individually with the built-in Image Gen tool for App-owned Skill presets; five research, writing and handraw-style poster covers remain after the other media/web preset retirement. No provider credentials or third-party fetched content were used. Each selected output was visually inspected, then resized and encoded as an 864 × 512 JPEG for the 27:16 card slot. Application UI text remains outside the cover; text intrinsic to poster/deck artwork remains inside the image.

All prompts specified a full-bleed landscape cover with no UI frame, border, rounded corners, watermark or external brand logo. The reference supplied editorial density, tactile-paper treatment and a restrained cream/blue/coral palette.

| Final asset | Prompt / art direction |
| --- | --- |
| `om-research-brief.jpg` | Research papers, restrained blue charts, open notebook and coffee on an ivory desk; soft daylight and tactile paper; no readable text. |
| `om-source-compare.jpg` | Top-down overlapping cream research folios with blue/terracotta charts, translucent paper and a small magnifying lens; no readable text. |
| `om-article-writer.jpg` | Cream editorial stationery and manuscript pages with abstract cobalt article lines, fountain pen and orange coffee cup; no readable text. |
| `om-text-rewriter.jpg` | Cobalt paper-cut hands revising a cream manuscript with blue pencil and coral editorial strokes; buttercream craft texture; no readable text. |
| `om-poster-maker.jpg` | Engraved cobalt galloping horse on warm pale paper with integrated bold coral serif typography: “MAKE SOMETHING.” |

Consumed by `features/ai-console/new-task-covers.ts`; the renderer bundles these local assets with the application.
