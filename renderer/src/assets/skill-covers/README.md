# New-task recommendation covers

Original raster assets generated individually with the built-in Image Gen tool for the twelve App-owned Skill presets. No provider credentials or third-party fetched content were used. Each selected output was visually inspected, then resized and encoded as an 864 × 512 JPEG for the 27:16 card slot. Application UI text remains outside the cover; text intrinsic to poster/deck artwork remains inside the image.

All prompts specified a full-bleed landscape cover with no UI frame, border, rounded corners, watermark or external brand logo. The reference supplied editorial density, tactile-paper treatment and a restrained cream/blue/coral palette.
