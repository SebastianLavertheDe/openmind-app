# Package Schema

Package path:

`creative/01-内容生产/文稿库/02-制作中/YYYYMMDD-选题名/`

Files:

- `topic-brief.md`: selected topic, editor judgment, platform direction, risk notes, and source hints from ai_topic.
- `xiaohongshu-draft.md`: Xiaohongshu writing task placeholder.
- `wechat-draft.md`: WeChat writing task placeholder.
- `twitter-thread.md`: Twitter/X writing task placeholder.
- `manifest.json`: package metadata and platform task states.
- `review.md`: optional review placeholder.
- `assets/`: optional future screenshot and cover assets.

Task files are not final drafts. `creative-writing` replaces them with platform-ready drafts after full material search.
