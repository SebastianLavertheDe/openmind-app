# Daily Writing Orchestrator

> All paths in this document are relative to the content root `$OPENMIND_ROOT` — the data root the user selected in openmind-app. Always resolve via `$OPENMIND_ROOT`, never assume a fixed location.

This skill decides which social-media topic should be written today and creates the writing package.

It uses the three-step creation method:

1. 获取信息: carry forward the source topic context, links, risks, and evidence requirements.
2. 找角度: package the topic with an explicit angle design so writing does not become information搬运.
3. 创作: hand the package to `creative-writing`, which writes the final platform draft with story rhythm.

Input (relative to the content root $OPENMIND_ROOT):

`creative/01-内容生产/选题管理/ai_topic_YYYY-MM-DD.md`

Output (relative to the content root $OPENMIND_ROOT):

`creative/01-内容生产/文稿库/02-制作中/YYYYMMDD-选题名/`

It selects and packages. It does not write the final copy.

## Responsibilities

Do:

- Read the daily `ai_topic_YYYY-MM-DD.md` generated by `ai-media-topic-selector`.
- Select exactly one topic by default: `今日最终推荐`.
- Allow overrides with `--topic`, `--topic-index`, `--platform`, and `--topic-file`.
- Create a standard package under `文稿库/02-制作中/`.
- Generate `topic-brief.md`, platform task files, `manifest.json`, and optional `review.md`.
- Add angle-design fields to `topic-brief.md`: obvious angle to avoid, recommended angle, reader surprise, opening scene, and story line.
- Mark the package as ready for `creative-writing`.

Do not:

- Write Xiaohongshu, WeChat, or Twitter final drafts.
- Replace `creative-writing`'s full local material search.
- Collect screenshots before drafts exist.
- Use `daily-topic-selector` as the social-media writing source.

## Commands

Default today:

```bash
python3 daily-writing-orchestrator/scripts/create_writing_package.py \
  --content-root /path/to/content-root
```

Specific date:

```bash
python3 daily-writing-orchestrator/scripts/create_writing_package.py \
  --content-root /path/to/content-root \
  --date 20260513
```

Specific topic within a date:

```bash
python3 daily-writing-orchestrator/scripts/create_writing_package.py \
  --date 20260513 \
  --topic "Claude Code"
```

Candidate row:

```bash
python3 daily-writing-orchestrator/scripts/create_writing_package.py \
  --date 20260513 \
  --topic-index 2
```

One platform only:

```bash
python3 daily-writing-orchestrator/scripts/create_writing_package.py \
  --date 20260513 \
  --platform wechat
```

## Selection Rules

Default:

1. Read `## 1. 今日最终推荐`.
2. Use `### 今日最值得优先写的主题`.
3. Create one package only.

Override:

- `--topic "keyword"` with `--date`: search that day's final recommendation, candidate pool, Xiaohongshu headings, and WeChat headings.
- `--topic-index N`: select the Nth row from `## 4. 今日候选热点池`.
- `--topic-file`: use an explicit ai_topic file.

## Hand-Off

After the package exists, `creative-writing` takes over.

`creative-writing` should:

- If the user does not specify a topic, use today's package generated by this skill.
- Search the full local `$OPENMIND_ROOT` material library before writing.
- Confirm or improve the package's angle design before drafting.
- Read the platform methodology.
- Replace task files with real drafts.
- Keep the package in `文稿库/02-制作中/` until the user says `发布了`.
