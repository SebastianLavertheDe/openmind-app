# Source rules

Use the current user's material first, followed by local content for the selected date. If using adjacent dates, label their dates. Open public links only when browsing is authorized by the current task.

Source selection follows only `topicPrompt`, each platform's `prompt` and additional preferences. No source platform, domain or author is excluded unless the user configured that rule. Prefer primary evidence for factual claims; distinguish a social post's opinion from independently supported facts. Keep the original URL and local file reference for every recommendation. State uncertainty and missing material instead of completing facts from memory.
