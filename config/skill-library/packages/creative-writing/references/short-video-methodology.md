# 短视频方法论

> 基于数据沉淀的短视频运营方法论

## 开头方法论（前3秒）

### 高完播率开头类型

1. **问题型**：`你有没有遇到过xxx？`
2. **反常识型**：`xxx其实是错的`
3. **数字型**：`3个方法让你xxx`
4. **痛点型**：`为什么你总是xxx`
5. **悬念型**：`接下来这个xxx会改变你`

### 开头禁忌

- 自我介绍
- 废话铺垫
- 节奏太慢

## 内容节奏

- **信息密度**：每3-5秒一个信息点
- **情绪起伏**：不要一直平淡
- **视觉变化**：画面要有变化

## 结尾设计

- **行动号召**：关注/点赞/评论
- **悬念预告**：下期内容
- **金句收尾**：升华主题
