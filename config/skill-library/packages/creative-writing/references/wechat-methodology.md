# 公众号方法论

> 基于数据沉淀的公众号运营方法论

## 标题方法论

### 高打开率标题公式

1. **悬念型**：`xxx，结果xxx`
2. **干货型**：`xxx的N个方法`
3. **故事型**：`我是如何xxx的`
4. **观点型**：`为什么我认为xxx`
5. **清单型**：`xxx必看的N个xxx`

### 标题长度

- 建议：15-25字
- 太短：信息量不够
- 太长：显示不全

## 内容结构

### 长文结构

1. **开头**（100-200字）：痛点/故事/问题
2. **正文**：分段清晰，每段一个观点
3. **结尾**：总结/升华/互动

### 排版原则

- 段落不超过4行
- 重点加粗
- 适当留白
- 图片辅助

## 发布时间

- 早：7:00-9:00
- 中：12:00-13:00
- 晚：20:00-22:00
