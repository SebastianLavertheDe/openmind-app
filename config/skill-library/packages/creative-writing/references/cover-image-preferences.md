# 封面图生成偏好

## 风格偏好

- **主色调**: 科技蓝、深灰色系
- **设计风格**: 现代简约、科技感
- **字体**: 黑体、思源黑体
- **布局**: 左右结构或上下结构

## 内容偏好

- **标题处理**: 提取核心关键词，突出数字和冲突点
- **副标题**: 简短说明，增加信息量
- **视觉元素**: 适当使用图标、线条、几何图形

## 尺寸规格

| 平台 | 尺寸 | 说明 |
|------|------|------|
| 公众号封面 | 900×500px | 首图 |
| 小红书封面 | 1242×1660px | 3:4比例 |
| 视频号封面 | 1080×1260px | — |

## 禁忌

- 不要过于花哨
- 不要使用低质量素材
- 文字不要过多
- 避免信息过载
