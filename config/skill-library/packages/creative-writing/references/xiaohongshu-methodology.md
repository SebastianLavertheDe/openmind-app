# 小红书方法论

> 基于数据沉淀的小红书运营方法论

## 标题方法论

### 高点击标题公式

1. **数字+痛点**：`3个方法让你xxx`
2. **反常识**：`为什么xxx反而更好`
3. **身份认同**：`xxx的人都在做这件事`
4. **紧迫感**：`别再xxx了`
5. **好奇心**：`原来xxx是这样的`

### 标题禁忌

- 太长（超过20字）
- 太抽象（没有具体信息）
- 太平淡（没有情绪）

## 封面方法论

### 高点击封面要素

- 大字标题（3-7个字）
- 对比/冲突
- 人脸/表情
- 数字

### 封面禁忌

- 字太小
- 信息太多
- 颜色太杂

## 内容结构

### 图文结构

1. **开头**：痛点/共鸣/反常识
2. **中间**：干货/方法/案例
3. **结尾**：总结/金句/互动

### 短视频结构

1. **前3秒**：钩子（决定完播率）
2. **中间**：价值输出
3. **结尾**：行动号召
